**Open WebUI does not pick this up from a chart value.** MCP tool servers are
UI-managed state stored in Open WebUI's database, with no declarative env var
(docs.openwebui.com/features/extensibility/mcp). Register it once, by hand:

  Settings -> Admin -> Integrations -> External Tool Servers -> + Add Connection
    Type: MCP (Streamable HTTP)
    URL:  the address above, including the /mcp path
    Auth: Bearer, with the token from:
          kubectl -n {{ .Release.Namespace }} get secret mcp-cube-secret \
            -o jsonpath='{.data.OHDP_MCP_AUTH_TOKEN}' | base64 -d

Four tools should appear: list_metrics, describe_metric, run_metric_query,
explain_query. There is no SQL tool and no way to express one (ADR-0016) — if a
fifth tool ever shows up here, something changed that should not have.
