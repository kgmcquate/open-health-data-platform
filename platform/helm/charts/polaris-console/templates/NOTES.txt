polaris-console {{ .Chart.Version }} deployed as {{ include "polaris-console.fullname" . }}
(image {{ include "polaris-console.image" . }}).

Internal only — no ingress. Reach it with:

  make -C platform/helm console
  open http://localhost:8080

or by hand:

  kubectl -n {{ .Release.Namespace }} port-forward svc/polaris 8181:8181 &
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "polaris-console.fullname" . }} 8080:{{ .Values.service.port }}

Log in with the `{{ .Values.config.polarisRealm }}` root principal (Client Credentials):

  kubectl -n {{ .Release.Namespace }} get secret polaris-principal \
    -o jsonpath='{.data.OHDP_ICEBERG_CREDENTIAL}' | base64 -d

The value is `<clientId>:<clientSecret>` — split on the colon for the two fields.

If API calls fail with a CORS error, check that values/polaris.yaml has
`cors.enabled: true` with `http://localhost:8080` in `allowedOrigins`, then
`make -C platform/helm polaris`.
